# physics+ by cogotl
### a powerful and customizable physics extension for TurboWarp
### Init instructions:
run `chmod +x init.sh && ./init.sh` in terminal
### Build instructions:
run `npm run package` or `npm run build` in terminal
### About
Using the Matter.js library, I have created a powerful physics extension for TurboWarp.
### Feature comparison:
| Feature | Griffpatch's physics extension | Physics+ by cogotl |
|--------|:--------|--------------|
| Library | Box2D port | Matter.js |
| Performance | Optimized | More complex, slower on older systems |
| Physics simulation | Accurate | Accurate |
| Hitbox size | A bit harder to change | Easily changeable |
| Friction, bounciness, etc. | Easily changeable | Control WIP |
| Joint creation, etc. | Little-none | Fully customizable and modular |
| Border | Fewer options | More customizability |
| Maturity | Stable release | Early beta |
| Known issues | Few reported | Expect bugs |
